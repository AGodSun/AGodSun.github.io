## [题目](https://leetcode.cn/problems/linked-list-cycle-ii/description/?envType=study-plan-v2&envId=top-100-liked)：

```java
142. 环形链表 II
    
给定一个链表的头节点  head ，返回链表开始入环的第一个节点。 如果链表无环，则返回 null。

如果链表中有某个节点，可以通过连续跟踪 next 指针再次到达，则链表中存在环。 为了表示给定链表中的环，评测系统内部使用整数 pos 来表示链表尾连接到链表中的位置（索引从 0 开始）。如果 pos 是 -1，则在该链表中没有环。注意：pos 不作为参数进行传递，仅仅是为了标识链表的实际情况。

不允许修改 链表。
```



### 方法1：

```java
初始化一个Set，遍历Node节点，将每个遍历到的节点加入到Set中，在加入前判断Set中是否存在当前遍历的节点，存在就返回当前节点
```

```java
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public ListNode detectCycle(ListNode head) {
        if(head == null || head.next == null){
            return null;
        }
       Set<ListNode> container = new HashSet<>();
        while (head.next != null) {
            if(container.contains(head)){
                return head;
            }
            container.add(head);
            head = head.next;
        }
        return null;
    }
}
```



### 方法2：

```java
利用快慢指针找到第一个相遇的节点，再分别从slow和head节点开始已相同速度遍历，第一个相等的节点就是循环的入口节点
```

##### 利用的条件：

```java
设定如下：
  设a为链表头结点到环形入口节点的距离
  b为slow指针与fast指针相遇时，从环形入口到相遇节点的距离
  L为环的长度

那么必然存在 a+b = KL (k>=0)：推导如下：
  fast和slow在环内一点相遇，那么fast必然比slow多走了K倍环的距离
  fast - slow = KL
  2(a+b) - (a+b) = KL
  a+b = KL

解题思路：
   已知：1.fast和slow第一次相遇时，相遇点为 a+b（环外距离+环内距离）
    	2.a+b = KL
    	3.a为链表头结点到环形入口节点的距离
    
   由1、2推导出：从fast和slow第一次相遇节点开始，再走a的距离会回到环形入口
   再加上已知3，得出：从head和slow以相同的速度走会同时到环形入口，即可得到环形入口的节点
```

```java
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public ListNode detectCycle(ListNode head) {
        if(head == null || head.next == null){
            return null;
        }
        ListNode slow = head;
        ListNode fast = head;
        while (fast.next != null && fast.next.next != null) {
            fast = fast.next.next;
            slow = slow.next;
            if(fast == slow){
                while (true){
                    if(slow == head){
                        return slow;
                    }
                    slow = slow.next;
                    head = head.next;
                }
            }
        }
        return null;
    }
}
```
